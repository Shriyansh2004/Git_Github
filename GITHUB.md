# Git - Github Study!!
- Create your project
- Initiate `git init` inside your codebase
- Do `git add .` for adding the changed file
- Do `git commit -s -m "Commit Message"` for commit
- Then create a "Repository" on Github
- Then Connect that repo with your source code
- Do `git push`
