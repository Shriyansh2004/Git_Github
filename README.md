# In this repo we are learning how git and github works:
    Git Commands:
    - git add <file name> or git add . ## add all chages
    - git commit -s -m "Commit message"  ## commit your changes with a message
    - git push ## push the changes to your branch and the remote repo
    - git status ## check the status
    - git branch ## check you are on which branch
    - git checkout -b branch ## create branch and checkout to that created branch
    - git pull origin <branch> ## take pull from a particular branch
